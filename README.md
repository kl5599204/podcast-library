# Podcast Library

個人 Podcast 講稿與研究資料庫。第一份專題：**《苦盡柑來遇見你》**。

## 本地預覽
直接以瀏覽器開啟 `index.html`。

## GitHub Pages
Repository → **Settings → Pages** → Build and deployment → Source 選 **GitHub Actions**。
之後每次更新 `index.html` 都會自動重新部署。

> 注意：GitHub Pages 的公開可見性和私人 repository 的可用方案，取決於 GitHub 帳戶方案與組織設定。請先確認 Pages 設定頁可啟用。網站本身沒有登入保護；如部署成公開 Pages，內容亦會公開。不要放入私人或敏感資料。

## 網站功能
- 響應式排版，支援手機與桌面
- 側邊導覽、全文搜尋
- 16 集逐集展開／按篇章篩選
- 角色、歷史時間線、濟州文化、討論方向及資料來源
- 圖片來源與授權標示

## 新增下一份 Podcast
複製專題頁的內容結構，新增一個專題頁，再在首頁加入新卡片即可。
